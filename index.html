Relational Database Design & SQL Queries

In this project, I utilized a retail dataset sourced from Kaggle to design and develop a relational database using MySQL Workbench. I created and established relationships between multiple tables, imported the dataset, and developed SQL queries to address real-world business questions. Through this analysis, I explored key retail performance metrics, including sales revenue, product profitability, customer purchasing behavior, and return rates, to uncover meaningful business insights.
